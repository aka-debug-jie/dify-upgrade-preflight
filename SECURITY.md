# Security policy

Do not submit secrets, deployment configuration, raw Compose output, `.env` files, logs, databases, host paths, or container identifiers to public issues, pull requests, or discussions.

For a suspected vulnerability, use a private GitHub Security Advisory for this repository when private reporting is available. If it is unavailable, contact the repository owner privately through GitHub without including sensitive material. Provide only a minimal synthetic reproduction until a private channel is established.

This project is not a production upgrade service. It does not claim that any Dify version pair, configuration, backup, migration, or deployment is safe to upgrade.
