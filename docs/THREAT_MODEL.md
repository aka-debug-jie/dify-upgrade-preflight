# 威胁模型与诚实边界

## 在范围内

不可信但在采集期间保持不变的配置/规则/来源文本；恶意路径、YAML、JSON、env值、报告内容；漏配和未知版本；规则证据不完整；意外读取凭据；运行输出泄密；模型把外部文档当指令。

## 不声称防御

被攻陷的Python/Compose二进制、操作系统内核、同一权限恶意进程在预审与解析之间替换文件、调试器读取内存、操作系统swap/core dump、用户自己把报告上传到不可信网站。

首版采集要求输入目录在本次采集期间冻结；前后记录stat/hash以发现变化。该检查不等于完全消除TOCTOU攻击，也不等于沙箱。不能在README声称“可安全解析任意活跃恶意仓库”。

核心check只处理脱敏snapshot，攻击面更小。原始Compose采集调用受信任且固定版本的解析器；无法满足本地文件边界时只接受用户预先审核的snapshot，不提供静默不安全回退。

## 目录信任

内容hash只能证明与某个baseline相同，不能证明发布者身份。产品信任安装包内审核manifest或用户明确批准的本地manifest；未知自定义catalog记为untrusted，不给放行式结论。

## 资源与隐私承诺

产品不主动持久化原始配置，不输出秘密。宿主机已有的源.env当然仍在磁盘上。工具层承诺与操作系统内存/备份行为分开描述，不使用“绝对不会泄露”措辞。

## 升级结果

工具提供有限范围风险分析，不是证明系统升级一定成功的形式化验证，也不代替管理员备份和回滚准备。
