# 审批与契约保护

acceptance-lock.json 是启动基线，保护契约、schema、阶段提示词和 roadmap 的不可变内容；它不代表人工已批准当前设计。

approvals.yaml 初始为空。Codex 只能在看到 owner 的真实批准消息后记录审批：id、对象、sha256、决定、批准人角色、消息引用、记录时间。不得以模型身份代签，不得预填日期/批准意见。

审批绑定精确内容，变化后旧审批不适用。真实资料来源的固定状态与规则批准是两件事。

P01 实现 scripts/validate_governance.py。它检查受保护文件和 roadmap 骨架未变，状态更新只发生在允许字段；审批完整但没有实际消息来源仍视为缺失。

SHA 用于一致性，不提供身份认证。公开规则目录还需明确的可信发布来源。未经授权不得自动重建 baseline 来让校验通过。
